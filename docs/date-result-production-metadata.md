# Date production metadata in result cards

Date result subtitles now include:

- match count
- kickoff range
- time-zone summary

Example:

```txt
Jun 14
4 matches · 12:00–20:00 · CT/ET
```

For one-match dates:

```txt
Jul 19
1 match · 15:00 · ET
```

This aligns Date result cards with the metadata already shown in date chips.
