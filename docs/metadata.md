# HTML metadata

The app includes only stable metadata for now:

- document title
- description
- theme color
- Open Graph title / description
- Twitter title / description

## Placeholder social assets

Placeholder `favicon.svg` and `og-image.svg` assets were intentionally removed.

Do not add a social preview image until the production map design and production tournament data are in place. A poor or inaccurate OGP image is worse than no image because it sets the wrong expectation for the public version.

## App naming

The app name intentionally avoids `FIFA` in the product title to reduce official-affiliation ambiguity.

Use:

```txt
World Cup 2026 Atlas
```

Avoid implying official status unless the app has explicit permission and the data/source policy is ready.
