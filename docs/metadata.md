# HTML metadata

The app includes basic metadata for public sharing:

- document title
- description
- theme color
- Open Graph title / description / image
- Twitter card metadata
- SVG favicon

The app name intentionally avoids `FIFA` in the product title to reduce official-affiliation ambiguity.

The OGP image is a lightweight SVG stored in:

```txt
public/og-image.svg
```

For GitHub Pages, absolute metadata asset paths currently use:

```txt
/world-cup-2026-atlas/
```

If the repository name changes, update these paths in `index.html`.
